# Library Management System

## الاسم واللقب:
- الاسم: هشام لخويمس
- اللقب: الفوج 2

## وصف المشروع
نظام مكتبة رقمية بسيط يتيح إدارة الكتب والمستعيرين وعمليات الإعارة والاسترجاع.

## كيفية التشغيل
- افتح المشروع في بيئة تطوير مثل IntelliJ أو VS Code.
- شغّل الملف `Main.java` لتنفيذ التطبيق.

## ملاحظات التصميم
- تم تطبيق مفاهيم البرمجة الكائنية مثل التغليف (Encapsulation)، الوراثة (Inheritance)، وتعدد الأشكال (Polymorphism).
- تم تقسيم المشروع إلى ملفات منفصلة داخل المجلدات المناسبة (`models` و `interfaces`).
- الواجهة المستخدمة هي واجهة نصية بسيطة (Console Application).

## ملاحظات إضافية
- تم استخدام Git لإدارة الإصدارات.
- كل commit يحتوي على تغييرات محددة وملائمة.
